# 🏥 患者监护系统 (Patient Monitoring System)

《软件工程》综合实验 —— 选题 14

## 📖 项目简介

目前住院病人主要由护士人工护理，这种方式存在人力资源紧张、响应不及时等问题。
本系统以计算机为中心，实现：

- ✅ **实时监测** — 随时接收每位病人的生理信号（脉搏、体温、血压、心率等）
- ✅ **自动记录** — 定时记录病人情况，形成患者日志
- ✅ **智能报警** — 当生理信号超出医生规定的安全范围时，自动向值班护士发出警告
- ✅ **报告生成** — 护士/医生可按需查询并打印指定病人的病情报告

## 🛠 技术栈

| 分类 | 选型 |
|------|------|
| 语言 | Python 3.10+ |
| 数据库 | SQLite 3 |
| GUI | tkinter (Python 标准库) |
| 定时任务 | threading.Timer |

**零外部依赖**，Python 标准库即可运行。

## 🚀 快速开始

```bash
# 克隆/进入项目目录
cd patient-monitor

# 默认 Web 模式（推荐）：启动本地服务并自动打开浏览器
python3 main.py

# tkinter 桌面 GUI 模式（可选）
python3 main.py --gui

# 命令行交互模式（可选）
python3 main.py --cli
```

> Web 模式基于 Python 标准库，零第三方依赖，WSL / Windows / Linux 全平台可用。
> WSL 下若浏览器未自动弹出，请手动访问终端打印的地址（默认 http://127.0.0.1:8000）。

首次启动会自动：
1. 在项目根目录 `data/` 下创建 SQLite 数据库
2. 插入 4 名示例患者和默认阈值
3. 启动定时监控线程（30 秒采集一次）

## 📋 功能清单

| 模块 | 功能 |
|------|------|
| 患者管理 | 新增 / 出院 / 列表查询 / 搜索 |
| 阈值管理 | 5 项生理指标上下限设置 |
| 实时监测 | 30 秒周期采集，异常自动报警弹窗 |
| 报警处理 | 待处理报警列表 / 一键确认 |
| 历史日志 | 时间轴记录查询 / 范围过滤 |
| 报告生成 | 单人完整病情报告（含统计）/ 保存为文件 |

## 📊 数据库表

| 表名 | 说明 |
|------|------|
| patient | 患者基本信息 |
| threshold | 每项指标的安全阈值 |
| log | 生理信号定时采集日志 |
| alarm | 超限报警记录 |
