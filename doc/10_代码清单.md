# 10. 代码清单

> 以下列出全部源码文件及行数统计。完整代码见项目源码目录 `src/` 和根目录 `main.py`。

## 9.1 文件清单

| 文件 | 行数 | 说明 |
|------|------|------|
| main.py | ~460 | 主程序入口 + tkinter GUI |
| src/utils/db.py | ~120 | 数据库初始化与连接 |
| src/models/patient_dao.py | ~60 | 患者数据访问对象 |
| src/models/threshold_dao.py | ~50 | 阈值数据访问对象 |
| src/models/log_dao.py | ~60 | 日志数据访问对象 |
| src/models/alarm_dao.py | ~70 | 报警数据访问对象 |
| src/services/patient_service.py | ~40 | 患者业务逻辑 |
| src/services/monitor_service.py | ~140 | 定时采集 + 阈值检测 + 报警 |
| src/services/report_service.py | ~130 | 报告生成 |
| **合计** | **~1130** | |

## 9.2 代码索引

```
patient-monitor/
├── main.py                          ← 从这里启动
├── src/
│   ├── utils/
│   │   └── db.py                    ← DB_PATH, init_database()
│   ├── models/
│   │   ├── patient_dao.py           ← PatientDAO.get_all(), .insert(), .discharge()
│   │   ├── threshold_dao.py         ← ThresholdDAO.get_by_patient(), .upsert()
│   │   ├── log_dao.py               ← LogDAO.insert(), .get_latest(), .get_range()
│   │   └── alarm_dao.py             ← AlarmDAO.insert(), .exists_pending(), .confirm()
│   └── services/
│       ├── patient_service.py       ← PatientService.list_active(), .add()
│       ├── monitor_service.py       ← MonitorService.start(), ThresholdService.check()
│       └── report_service.py        ← ReportService.generate(), .save_report()
```

## 9.3 运行

```bash
python3 main.py          # 启动 GUI
python3 test/test_services.py  # 运行自动化测试
```
