# 00. 绪论

## 1.1 项目背景

随着人口老龄化进程加速，住院重症监护（ICU）和普通病房的患者监护工作变得日益繁重。
传统的人工监护模式存在以下痛点：

- **人力资源紧张**：护士需要轮班值守，一人难以同时照看多位危重病人
- **响应不及时**：护士无法 24 小时盯着每位患者，病情变化可能被延迟发现
- **数据不连续**：人工记录的生命体征存在遗漏、延迟和主观性

计算机辅助监护系统可以有效弥补上述不足。本项目即来源于《软件工程》课程综合实验选题 14——**患者监护系统**。

## 1.2 项目目标

构建一个以计算机为中心的患者监护系统，实现：

1. **自动采集**：每隔固定周期（30 秒）为每位在院病人生成并记录生理信号
2. **智能检测**：将实时值与医生设定的安全阈值自动比对
3. **主动报警**：超限立即弹窗提醒值班护士
4. **日志追溯**：所有历史数据可按时间范围查询
5. **报告生成**：一键生成患者病情监测报告

## 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 实用性 | 聚焦护士和医生的实际工作流，避免功能堆砌 |
| 可用性 | GUI 操作简单直观，关键路径 ≤ 3 步 |
| 可扩展 | 模块化设计，新增生理信号类型无需改动核心逻辑 |
| 可靠性 | 报警去重避免刷屏，数据持久化防止丢失 |
